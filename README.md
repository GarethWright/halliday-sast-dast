# Halliday wearable security assessment

This repository contains the sanitised deliverable from an authorised static and dynamic security assessment of the Halliday G2 Android companion application and its wearable-update path.

The source APK, JADX output, Android bugreport, Bluetooth HCI captures, device identifiers, credentials, tokens, and firmware binaries are intentionally excluded. They contain sensitive evidence and are retained outside this repository under the engagement's evidence-handling process.

See [SECURITY_ASSESSMENT.md](SECURITY_ASSESSMENT.md) for findings, the reconstructed connection/update protocol, and priority remediation actions.
